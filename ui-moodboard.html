Principles

  • Desk is a navigable home, not a gate — conventional nav always available.
  • Each object is a real button/link with accessible label and keyboard focus.
  • Warm muted pastels, rounded corners, soft shadows, paper texture.
  • Subtle ambient motion (lamp glow, dust motes) — disabled under prefers-reduced-motion.
  • Mobile: vertical stack of object cards instead of isometric room.
  • Empty states use cozy illustrations; progress subtly changes the scene.
